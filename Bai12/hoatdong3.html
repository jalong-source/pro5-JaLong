30 PHÚT · DYNAMIC RENDER

Dynamic UI Render

Tự động sinh các thẻ card sản phẩm từ mảng Object thông qua phương thức map().

Đổ dữ liệu tự động lên giao diện HTML (Dynamic UI Render)

Không viết cứng HTML! Toàn bộ danh sách card dưới đây được duyệt tự động bằng map() từ file data.js.

// Đổ dữ liệu tự động với map()
const catalog = document.getElementById('catalog-grid');
catalog.innerHTML = PRODUCTS_DATA.map(p => `
  <div class="card">
    <h4>${p.name}</h4>
    <p>${p.price.toLocaleString('vi-VN')} đ</p>
  </div>
`).join('');
Hoạt động 3: Thay vì viết HTML thủ công cho từng sản phẩm, sinh viên dùng vòng lặp map() hoặc forEach() để tự động tạo ra các thẻ div.card trên trang web từ mảng dữ liệu.
