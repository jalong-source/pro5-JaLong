Object Identity

Định danh đối tượng cá nhân với thuộc tính và phương thức tính toán tự động.

Định danh đối tượng (Object Identity) & Phương thức

Nhấn nút để kích hoạt phương thức của đối tượng.
const user = {
  name: "Trần Gia Long",
  age: 20,
  major: "Công nghệ thông tin - LHU",
  skills: ["HTML5", "CSS3", "JavaScript", "AI Prompting"],
  getBirthYear() {
    return new Date().getFullYear() - this.age;
  },
  introduce() {
    return `Xin chào, tôi là ${this.name}, ${this.age} tuổi, theo học ${this.major}. Kỹ năng nổi bật: ${this.skills.join(', ')}.`;
  }
};
Vibe Coding Prompt: "Làm thế nào để thêm một phương thức (function) vào bên trong Object để nó tự tính năm sinh dựa trên thuộc tính tuổi?" -> Sử dụng cú pháp hàm trong object và từ khóa this.age.
