Đóng gói sản phẩm & Hướng dẫn Deploy Live

Kiểm tra checklist đóng gói, viết README.md chuyên nghiệp và phát hành sản phẩm lên GitHub Pages.

1. Checklist đóng gói sản phẩm hoàn thiện

  • ✅ Tách mã nguồn thành 3 file độc lập: data.js, logic.js, features.js.
  • ✅ Thêm file README.md chuẩn Vibe Coding (giới thiệu dự án, vai trò thành viên, 5 câu prompt quan trọng).
  • ✅ Thêm file prompt_log.md ghi nhận hành trình làm việc và sửa lỗi cùng AI.
  • ✅ Kiểm tra trang trên DevTools ở các độ phân giải: 375px (iPhone), 768px (iPad), 1200px (Desktop).

2. Quy trình phát hành GitHub Pages

  1. Commit mã nguồn hoàn thiện vào nhánh develop và tạo Pull Request vào main.
  2. Truy cập Settings của GitHub Repository -> chọn mục Pages.
  3. Tại phần Branch, chọn nhánh main và folder / (root) rồi nhấn Save.
  4. Sau 1-2 phút, đường link Live Demo chính thức sẽ sẵn sàng cho buổi thuyết trình Hackathon tuần 15!
Sản phẩm đã sẵn sàng chuyển giao cho buổi Demo Day!
