Bài 3: "AI Logic Explainer" — Dịch mã lỗi sang ngôn ngữ tự nhiên

Sử dụng tư duy logic để phân tích và "dịch" 3 trường hợp lỗi kinh điển mà người mới học JavaScript hay gặp sang ngôn ngữ tự nhiên.

Case 1: Lỗi đảo lộn thứ tự điều kiện trong If - Else

// ❌ ĐOẠN MÃ LỖI:
let diem = 9.5;

if (diem >= 5.0) {
  console.log("Trung bình");
} else if (diem > 8.0) {
  console.log("Giỏi");
}
// Kết quả thực tế in ra: "Trung bình" (Dù 9.5 là điểm Giỏi!)

🤖 AI "Dịch" luồng chạy từng bước:

• Bước 1: Biến diem nhận giá trị số 9.5.
• Bước 2: Trình duyệt gặp điều kiện đầu tiên: diem >= 5.0. Vì 9.5 >= 5.0 là ĐÚNG (true), khối lệnh in "Trung bình" được kích hoạt ngay.
• Bước 3: Khi nhánh if đầu đã thỏa mãn, JavaScript bỏ qua toàn bộ nhánh else if phía sau!

✔ Cách sửa chuẩn: Luôn kiểm tra điều kiện khắt khe nhất trước (sắp xếp giảm dần: > 8.0 rồi mới tới >= 5.0).

Case 2: Cạm bẫy so sánh lỏng lẻo (==) và ép kiểu bất ngờ

// ❌ ĐOẠN MÃ BẤT NGỜ:
console.log(0 == "");     // true!
console.log(0 == "0");    // true!
console.log("" == "0");   // false!

🤖 AI "Dịch" luồng chạy:

• 0 == "" (true): Toán tử == tự động ép chuỗi rỗng "" về số 0, mà 0 == 0 là true.
• 0 == "0" (true): Chuỗi "0" bị ép kiểu về số 0, kết quả là true.
• "" == "0" (false): Hai vế cùng kiểu chuỗi, JS so sánh nội dung ký tự: chuỗi rỗng khác chuỗi có chứa ký tự '0', kết quả là false!

✔ Quy tắc vàng: Luôn dùng toán tử so sánh nghiêm ngặt === (so sánh cả giá trị và kiểu dữ liệu).

Case 3: Lỗi quên ép kiểu khi nhận dữ liệu từ prompt()

// ❌ ĐOẠN MÃ LỖI:
let a = prompt("Nhập số a:"); // Nhập 5
let b = prompt("Nhập số b:"); // Nhập 10
let tong = a + b;
alert("Tổng là: " + tong);    // Kết quả ra "510" thay vì 15!

🤖 AI "Dịch" & Cách giải quyết:

Hàm prompt() luôn trả về dữ liệu kiểu String (chuỗi). Do đó "5" + "10" = "510" (nối chuỗi).

✔ Cách sửa: Dùng parseFloat() hoặc Number(): let tong = parseFloat(a) + parseFloat(b); (cho ra kết quả đúng: 15).
