Logic Đăng Nhập (Mô Phỏng)

Tạo 2 biến cố định lưu tài khoản chuẩn. Sử dụng cấu trúc điều kiện if với toán tử && để kiểm tra tính chính xác của tên người dùng và mật khẩu.

🔑 Tài khoản mẫu: username là admin, password là 123456.
Trạng thái xác thực: Đăng nhập thành công
Chi tiết phản hồi: Thông tin tài khoản chính xác!

Mã nguồn JavaScript mẫu

function moPhongDangNhap() {
  const USER_CHUAN = "admin";
  const PASS_CHUAN = "123456";

  let user = prompt("Nhập tên đăng nhập:", "admin");
  let pass = prompt("Nhập mật khẩu:", "123456");

  // Kiểm tra đúng cả 2 với toán tử &&
  if (user === USER_CHUAN && pass === PASS_CHUAN) {
    alert("Đăng nhập thành công! Chào mừng bạn.");
    console.log("Đăng nhập thành công");
  } else {
    alert("Thông tin không chính xác!");
    console.log("Thông tin không chính xác");
  }
}
