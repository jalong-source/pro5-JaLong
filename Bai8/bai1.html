Bài 1: "Hello JS Console" — Đối thoại với trình duyệt

Khai báo biến (let, const), phân biệt kiểu dữ liệu cơ bản (String, Number, Boolean) và thực hiện các phép toán số học trực tiếp trên Console.

1. Mã nguồn JavaScript thực hành

// 1. Khai báo biến với let và const
const myName = "Gia Long";       // String
let myAge = 20;                 // Number
const isStudent = true;         // Boolean

console.log("Họ tên:", myName);
console.log("Tuổi:", myAge);
console.log("Là sinh viên:", isStudent);

// 2. Thực hiện các phép toán cơ bản (+, -, *, /, %)
let a = 25;
let b = 5;

console.log("Tổng a + b =", a + b);           // 30
console.log("Hiệu a - b =", a - b);           // 20
console.log("Tích a * b =", a * b);           // 125
console.log("Thương a / b =", a / b);         // 5
console.log("Chia lấy dư 27 % 5 =", 27 % 5); // 2

2. Vibe Coding: Giải thích câu hỏi logic AI-First

Câu hỏi: "Tại sao khi cộng '10' + 20 trong JS lại ra '1020' mà không phải 30?"

Giải thích bản chất: Toán tử + trong JavaScript có 2 vai trò:

  • Cộng số học: Khi cả 2 vế đều là số.
  • Nối chuỗi: Khi có ít nhất 1 vế là chuỗi (String).

Vì '10' là chuỗi, cơ chế Ép kiểu ngầm định (Type Coercion) tự động biến số 20 thành chuỗi "20", dẫn tới phép nối chuỗi: "10" + "20" = "1020".

✔ Cách khắc phục: Dùng Number('10') + 20 hoặc parseInt('10') + 20 để ra kết quả 30.
