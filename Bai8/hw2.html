Kiểm Tra Số Chẵn / Số Lẻ

Nhập một số nguyên bất kỳ từ bàn phím. Sử dụng toán tử chia lấy dư % 2 để xác định chính xác số đó là chẵn hay lẻ.

Số đang kiểm tra: 18
Phép tính dư: 18 % 2 = 0
Kết luận: SỐ CHẴN

Mã nguồn JavaScript mẫu

function kiemTraChanLe() {
  let input = prompt("Nhập vào một số nguyên bất kỳ:", "18");
  if (input === null || input.trim() === "") return;

  let n = parseInt(input);
  if (isNaN(n)) {
    alert("Vui lòng nhập một số hợp lệ!");
    return;
  }

  // Kiểm tra số dư khi chia cho 2
  if (n % 2 === 0) {
    alert(`Số ${n} là SỐ CHẴN.`);
    console.log(`Số ${n} là số chẵn.`);
  } else {
    alert(`Số ${n} là SỐ LẺ.`);
    console.log(`Số ${n} là số lẻ.`);
  }
}
