Live Input

Lắng nghe sự kiện input trong JavaScript để phản hồi tức thì lên giao diện.

Lắng nghe sự kiện 'input' theo thời gian thực

Phản hồi tức thì (<h2 id="live-output">):

(Chờ bạn gõ phím...)

Số ký tự: 0
const input = document.getElementById('live-text-input');
const output = document.getElementById('live-output');
input.addEventListener('input', (e) => {
  output.textContent = e.target.value || '(Trống)';
});
