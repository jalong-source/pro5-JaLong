Light Switch

Thao tác bật tắt bóng đèn, biến đổi thuộc tính CSS và đổi trạng thái giao diện khi click.

Bật / Tắt bóng đèn & Dark Mode

💡

Trạng thái: ĐÈN TẮT

const toggleBtn = document.getElementById('toggle-btn');
let isOn = false;
toggleBtn.addEventListener('click', () => {
  isOn = !isOn;
  document.body.style.backgroundColor = isOn ? '#1f2923' : '#101513';
});
Prompt mẫu: "Viết mã JS để khi tôi click vào một nút có id là 'toggle-btn', nó sẽ thay đổi màu nền của body từ trắng sang đen hoặc ngược lại (Dark/Light mode đơn giản)."
