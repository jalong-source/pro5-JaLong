30 PHÚT · FOR LOOP

The Counting Machine

Dùng vòng lặp for để đếm từ 1 đến 100. Đổi chế độ để chỉ giữ lại số chẵn.

Chế độ đếm

for (let i = 1; i <= 100; i++) {
  if (i % 2 === 0) {
    console.log(i);
  }
}
Thử giải thích: let i = 1 khởi tạo biến đếm; i <= 100 là điều kiện tiếp tục; i++ tăng biến đếm sau mỗi lượt. Vì sao kiểm tra i % 2 === 0 chọn được số chẵn?
