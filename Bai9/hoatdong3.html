30 PHÚT · DRY REFACTORING

Refactoring Challenge

Thay phần tính thuế bị lặp lại bằng một hàm nhận lương và thuế suất, dùng lại cho nhiều mức lương.

Tính thuế với hàm dùng lại

Lưu ý: Thuế suất cố định chỉ dùng để học cách đóng gói hàm, không đại diện cho cách tính thuế thu nhập cá nhân thực tế.

Trước: lặp lại phép tính

const thueLuong1 = luong1 * 0.1;
const thueLuong2 = luong2 * 0.1;
const thueLuong3 = luong3 * 0.1;

Sau: tái sử dụng một hàm

function tinhThue(luong, tyLeThue) {
  return luong * tyLeThue / 100;
}

tinhThue(luong1, 10);
tinhThue(luong2, 10);
tinhThue(luong3, 10);
