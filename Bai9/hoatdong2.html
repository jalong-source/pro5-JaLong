45 PHÚT · FUNCTION + RETURN

Function Factory

Đóng gói phép tính diện tích vào tinhDienTich(dai, rong), sau đó gọi lại hàm với ba hình chữ nhật.

Ba lần gọi hàm

function tinhDienTich(dai, rong) {
  return dai * rong;
}

const dienTich1 = tinhDienTich(5, 3);
const dienTich2 = tinhDienTich(8, 4);
const dienTich3 = tinhDienTich(10, 6);
