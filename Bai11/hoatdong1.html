30 PHÚT · PREVENTDEFAULT

Stop the Page!

Chặn hành vi tải lại trang mặc định của Form bằng event.preventDefault().

Ngăn chặn hành vi mặc định (preventDefault)

Trang web chưa bị tải lại lần nào!
const form = document.getElementById('prevent-form');
form.addEventListener('submit', (e) => {
  e.preventDefault(); // CHẶN reload trang
  console.log('Dữ liệu nhập:', document.getElementById('demo-input').value);
});
Vibe Coding Prompt: "Tại sao tôi cần dùng preventDefault() khi xử lý Form bằng JavaScript?" -> AI giải thích: Theo mặc định của trình duyệt, submit form sẽ gửi HTTP request và tải lại toàn bộ trang. preventDefault() giữ trang ở nguyên trạng thái để JavaScript xử lý AJAX / DOM mà không bị gián đoạn.
