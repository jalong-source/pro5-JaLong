Smart Validator

Xây dựng bộ kiểm tra thông minh, hiển thị span thông báo đỏ và viền đỏ khi sai.

Smart Validator — Báo đỏ lỗi nhập liệu

Vui lòng nhập form để kiểm tra validation.
// Prompt mẫu tuần 11
if (username.length < 5) {
  errSpan.textContent = 'Tên quá ngắn';
  input.style.borderColor = 'red';
}
Prompt mẫu: "Viết mã JS để kiểm tra một Form: Nếu ô 'username' ít hơn 5 ký tự, hãy hiển thị lỗi 'Tên quá ngắn' vào một thẻ span có class 'error-msg' và đổi border của input sang màu đỏ."
